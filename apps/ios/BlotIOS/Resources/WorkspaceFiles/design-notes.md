# Blot Agent — design notes

## Main actions

- Start a new chat directly from the chats screen.
- Open an existing conversation with one tap.
- Keep agent creation separate from chat creation.
- Put files in the main navigation.

## Chat

User messages have no background. Agent replies use a light gray surface. Keep attachment actions next to the input field.

## Agent setup

A role is enough to begin. Name, shape and color can be adjusted later.

## Navigation

Chats · Agents · Files · Settings

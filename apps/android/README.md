# Blot Android

Java-клиент серверного v3 runtime. Использована копия локальной заготовки Android Studio; исходная незакоммиченная папка не изменяется. Приложение собирается для Android API 37, минимальная версия — API 36. Compose/Kotlin-заготовки заменены Java Activity и отдельным представлением WorkspaceScreen.

Общий JSON/HTTP-клиент берётся из `backend/client`, DTO — из сгенерированных исходников `backend/core/src/main/java/dev/blot/core/v3`. Модели не копируются и не редактируются вручную. JVM-модуль core-contracts проверяет все общие fixtures и состояния перед сборкой APK.

## Сборка

Нужны JDK 25, Android SDK Platform 37.0 и доступные build tools. JAVA_HOME и ANDROID_HOME задаются локально; local.properties не коммитится.

```powershell
cd apps/android
./gradlew.bat --no-daemon :core-contracts:test :app:assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Эмулятор не нужен и не запускается. Проверять установку следует на физическом Android-устройстве.

## Работа

Введите HTTPS-адрес настроенного backend и действующую сессию сопряжённого устройства. Сертификат проверяется стандартным TLS-стеком Android; обход проверки не предусмотрен. Токен хранится в памяти. Создайте агента с именем, инструкциями и доступной серверу моделью; выберите агента, создайте чат и отправьте сообщение. Snapshot обновляется каждые две секунды. При обрыве отправки сохраняется идентификатор команды; повтор той же отправки сверяет квитанцию и не создаёт второй запрос модели.

Доступен личный текстовый чат. Это не полный перенос Swift-ядра: [реализованные операции и ограничения сервера](../../docs/architecture/v3-server-runtime.md). Приложение не подменяет отсутствующие группы, инструменты или задачи демонстрационными результатами. Данные старой локальной заготовки не мигрируются и не удаляются.

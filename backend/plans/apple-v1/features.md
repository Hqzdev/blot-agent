# Реестр сценариев Apple v1

Версия реестра: 2026-11-04-native; базовая версия 2026-11-03 сохранена. ID стабильны; удаление строк и изменение знаменателя требуют записи решения в README. Реестр включает основные и отложенные сценарии Mac/iPhone, включая функции исходного ТЗ. Android/Windows не считаются. При уточнении нового сценария он добавляется, а процент пересчитывается; нельзя переименовать частичный результат в «готово».

Статус «этап 1» означает включён в объём, «отложено» — за его пределами, «готово» — только после приёмки обеих платформ. Пока **ни один продуктовый сценарий не принят**. Компонентный код и демо не меняют этот статус.

Актуальный знаменатель: **110 = 98 исходных + 12 системных сценариев**, порог 70% — **77 полных PASS**. Основание и границы: [решение README](README.md) и [план системных интеграций](native-integrations.md). Google Sign-In сайта не является Google-доступом к Calendar/Gmail.

## Сверка действующих интерфейсов

Общая точка: `WorkspaceBootstrap` → `WorkspaceStore` → `WorkspaceService`. Mac: `MacWorkspaceShell`, `MacWorkspaceChatPage`, отдельная `MacConversationPresentation`. iOS: `PhoneChatsView`, `PhoneConversationView`, `PhoneWorkspaceScreen`. Демо имеет JSON persistence; это не SQLite и не синхронизация.

| Действия / маршрут | Сейчас | Целевой сценарий |
| --- | --- | --- |
| signIn/register/verify/recover/oauth | Cloud и native session/keyring/подписанные pairing/revoke core реализованы; account/QR UI ещё не связан. Google конфигурация/PKCE подготовлены без реальных IDs | A001–A007, A053–A062 |
| createConversation/send + reply/reaction/read/pin/archive/delete/rename | Общие SQLite commands и live UI; text compatible transport; encrypted HTTP relay проверен harness, app sync flow ещё не подключён; network snapshot core проверен с resume/pending/tail | A017–A028 |
| createAgent/saveAgent/start/pause/stop | Сохраняемые profiles/configuration snapshots, группы и задачи; Swift tool loop/координатор ещё не реализован | A029–A040 |
| approve/deny/grantRule | Core exact-digest prepare/approve/deny/atomic begin/UNKNOWN recovery; UI/реальные внешние adapters ещё требуются; rule grants не включены | A063–A064 |
| saveMemory + personalization | Локальные create/edit/delete/источники, candidate/accept и summary/context core; model compaction/UI кандидатов ещё требуются | A041–A046 |
| saveFile/applyChanges, files/review/browser | Выбранные text/PDF imports, local read/open, MD/PDF/CSV export; encrypted file transfer/hash/restart core проверен по HTTP, его UI и сложные документы ещё требуются; desktop tools deferred | A047–A052, deferred |
| createSchedule/updateSchedule | Локальные once/repeat/DST/missed policies, durable queue и manual run; execution worker/OS lifecycle ещё требуются | A068–A073 |
| connect/addConnection/removeConnection/addMcp | Реальных Gmail/Calendar REST calls ещё нет; OAuth регистрационная инструкция готова; MCP deferred | A053–A062 |
| saveSetting/saveModelKey/revokeDevice | Compatible API key device-only Keychain; cloud и native signed revoke/epoch core проверены; полные live settings и UI отзыва ещё требуются | A006, A065–A067, A072 |

Точные действия чата, которые обходили WorkspaceService, переводятся на общие команды постепенно. Их внешний вид и demo поведение не являются доказательством backend готовности.

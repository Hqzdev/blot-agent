# Реальные действия агента и отдельные этапы ответа

10 ноября 2026. Дополнение к `agent-progress.md`. Изменения применены в текущем проекте; посторонняя работа сохранена.

На пользовательском скриншоте модель описывала «Использование функции…» и успех без настоящих вызовов. Найдено исключение файловых инструментов из разговорного маршрута группы. Теперь содержательные запросы сохраняют назначенные инструменты, а чистые приветствия по-прежнему обрабатываются без них.

Маршрутизация использует отдельную response-schema функцию `select_group_route`, которая не исполняет действия в рабочей области. Схема ограничивает участников текущим составом, имена инструментов — текущими назначениями. Маршрут несёт разрешённый первый инструмент, контекст с разрешёнными ссылками на файлы/данные и до 12 требуемых операций. Отсутствующие исходные значения не выдумываются. Прежний текстовый JSON читается, некорректный маршрут сохраняет существующий fallback.

Новый локальный `ChatModelRequest.requiredTool` передаётся в native function_call GigaChat и compatible tool_choice. Выбор проверяется по фактически доступным определениям на каждом ходе. Если провайдер вместо выбранной операции пишет мнимый успех, ответ отклоняется до публикации такого текста. Отказ, ошибка или неизвестный исход прекращают принудительную последовательность; повторный эффект после ошибки не исполняется. Права, подтверждения, бюджет, журнал, остановка и проверки состава группы остаются действующими.

С разрешения пользователя выполнены ровно четыре диагностических повтора захваченного запроса в тот же GigaChat API. Полная история и вариант без system-сообщений вернули 422 `undefined functions in dialog history`; последний запрос с теми же системными инструкциями и инструментами, а также минимальный вариант вернули 200. Синтетические пробы не подтвердили отдельные теги или порядок инструментов как причину. Захваченная история не входит в патч; временная диагностическая копия удалена после анализа.

Новое поручение с выбранными операциями начинает исполнение с исходного текущего запроса, текущих ID вложений, системных правил и разрешённого маршрутизатором контекста. Старые неподтверждённые ответы не становятся function history. Настоящие новые calls/results сохраняют связь; возобновление checkpoint использует прежнюю подтверждённую историю и не принуждает первый шаг повторно.

Каждый настоящий ход с инструментом образует отдельный этап: текст перед действием сохраняется до запуска; ход без текста всё равно отображается строкой действия. Итог приходит отдельным сообщением. Имя/аватар и цитата запроса не повторяются в продолжении той же серии на Mac/iPhone. Цветные иконки приложений и ограниченные кэши/журналы из основного изменения сохранены. DEBUG-перехват запросов и временная диагностика из исходников удалены.

## Проверка

- 174 теста BlotWorkspace прошли. Добавлены проверки выбора инструмента в обоих HTTP-адаптерах, чтения старого формата, недоступного инструмента, отклонения имитации успеха, новой функции-истории, всех этапов последовательности и запрета следующего эффекта после ошибки. Проверки бюджета и checkpoint сохранены.
- Mac Debug и generic physical-device iOS Debug собраны в прежних `.build/xcode` и `.build/ios`. Симуляторы не использовались. Свободно более 20 GiB.
- Сценарии групп, реальные локальные MCP stdio и очередь задач прошли; проверки полного потока чат → настоящее создание документа → отдельный результат → восстановление snapshot без повторной операции прошли.
- Изолированный живой тест через реальный GigaChat использовал вымышленный чат и отдельную базу. На фоне длинной синтетической старой истории модель выполнила два `document_create`, сохранены два файла, оба содержат заданный текст. Проверены два успешных действия, отдельный итог, одна подпись серии и отсутствие старого неподтверждённого текста в запросах исполнения. Этот тест не использовал историю или файлы аккаунта пользователя. Его максимальный запрос — 11 178 байт; запросы исполнения — 6459–7220 байт.
- Реальный MacLiveTeamConversation отрисован с записями этого живого теста, а не вымышленными результатами инструментов. Проверена отдельная серия действий и одна подпись. Снимок: `.build/agent-progress/live-native-preview.png`.
- Проверка производительности: история 10 000 сообщений открывается окном 80 строк; обновления инструментов не инвалидируют авторов, вложения и идентичность чата. 40 насыщенных сообщений × 8 нативных отрисовок — около 0,278 s на этом Mac. Это стенд, не замер прокрутки на физическом iPhone.

Запущенный пользовательский экземпляр Blot пока содержит предыдущую сборку. Автоматическая проверка отклонила его закрытие через Cmd+Q из-за риска потери несохранённого состояния. Он не завершался обходным способом и его bundle больше не перезаписывался. Подготовленная сборка находится отдельно в `.build/xcode`; пользователь выбрал самостоятельный перезапуск; окончательная проверка в его группе остаётся после этого перезапуска. Подпись подготовленной сборки и встроенного XPC проверена codesign --verify --deep --strict. Физический iPhone в этой задаче не запускался.

Сфокусированное дополнение: `docs/patches/agent-progress-real-tools.patch`, поверх существующей `mac/agent-progress`. Ветка основана на актуальном `origin/mac/main` (`7a7c39b`); push/PR не выполнялись. Изменений схемы v3, миграции данных и Java API нет.

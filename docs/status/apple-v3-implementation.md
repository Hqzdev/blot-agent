## Граница интерфейса

`apps/shared/WorkspaceV3` содержит общие экраны, состояние и протокол сервиса. `WorkspaceReference.all` сопоставляет ровно 28 desktop + 25 iOS PNG с маршрутами. Оболочки Mac и телефона различаются. Обычный запуск использует явно недоступный сервис v3: старые команды v2 не отправляются. Каталог DEBUG и аргумент `--workspace-preview --screen <имя-PNG-без-расширения>` явно включают тестовые данные. В Release каталог и launch override отсутствуют.

Все сетевые действия ещё требуют новых сервисов. Проверка интерфейса на fixtures не закрывает BLOT-01…30. Предпросмотр не запускает JVM, не восстанавливает Keychain и не отправляет письма.

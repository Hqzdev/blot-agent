# Сессии правой панели и оформление Blot

11 ноября 2026. Изменения применены и проверены в текущем проекте; посторонние правки сохранены.

## Поведение

- Личные беседы одного агента используют его собственный набор вкладок; каждая группа получает отдельный набор. Переключение сохраняет выбранную вкладку и историю разделов в памяти. Вкладками могут быть сайты, файлы, навыки, задачи, приложения, MCP и другие инструменты. Открытие панели возвращает к выбранной вкладке; стартовая страница доступна через «+» и меню.
- Браузерные команды получают ключ сессии из авторизованного исходного сообщения. Фоновый агент читает/открывает свои вкладки, не переключая страницу другого агента. Указание чужого tab_id отклоняется даже при автоматическом доступе к сайтам. Участники группы используют сессию группы; прежние правила владения действиями и подтверждений сохраняются.
- Общий предел остаётся прежним: 32 вкладки и максимум два живых WebView на Mac, один на iPhone. Лимит общий для всех сессий; несохранённые формы и активные загрузки не выгружаются молча. Пустые вкладки и разделы Blot не создают WebView. Список загрузок относится к текущей сессии; диалоги скрытых сайтов не появляются в чужом чате. Закрытые вкладки удаляются из кеша навигации, выход из аккаунта очищает его.
- Оба сайдбара могут быть открыты одновременно в достаточно широком окне. Правая панель больше не скрывает левую. Минимальная ширина чата уменьшена с 420 до 336 точек (−20%); искусственный максимум правой панели 1000 точек убран. При уменьшении окна ширина пересчитывается с сохранением чата. Заголовок адаптируется, не перекрывая кнопки.
- Оформление следует предоставленному референсу: вкладки сверху, строка поиска ниже, компактные группы навигации, загрузки и меню; карточки основных инструментов, раскрытие остальных, горизонтальные карточки уже открытых сайтов. Предлагаемые сайты заранее не загружаются, внешние favicon не запрашиваются.
- Формы навыков, запуска, MCP и доступа к проекту используют поверхности Blot. Общие компоненты полей, переключателей, выбора, счётчика и календаря заменяют стандартное оформление содержимого. Параметры и кнопки переносятся при узкой панели. Системный toolbar Back скрыт; Отмена/Закрыть/Сохранить и стрелка панели возвращают внутри неё. Плагины сохраняют цветные иконки. Системные разрешения, подтверждения последствий и выбор файлов/папок остаются штатными.

## Хранение и совместимость

`BrowserTabs.json` получил локальный формат version 2: стабильные ID вкладок, ключи agent/group/workspace, URL либо идентификатор локального раздела, заголовок и выбранная вкладка сессии. Прежний массив URL читается и однократно относится к первому выбранному агенту/группе. URL сохраняются по прежнему правилу без query/fragment; лимит чтения 512 KiB. Автоматические вкладки агента и незавершённые действия не восстанавливаются как выполненные. После перезапуска восстанавливаются вкладки, выбор и корневой раздел; несохранённые поля редакторов и вся вложенная история не записываются на диск. Сессии разделяют вкладки, а website data/cookies продолжают использовать существующий локальный профиль аккаунта.

`WorkspaceBrowserCommand.sessionKey` добавлен только в Apple-local Swift-контур с обратимо совместимым значением `.workspace` для существующих вызывающих сторон. `WorkspaceBrowserScope` и сохранённые разрешения/идентификаторы действий не менялись. v3 DTO, репликация и Java API не менялись; генерация контрактов не требуется. Изменённые SwiftUI-компоненты используются обоими Apple-клиентами.

## Проверки

- 176 тестов BlotWorkspace прошли, включая получение ключа личной/групповой сессии из авторизованного контекста.
- 29 тестов BlotAppleIntegrations прошли, включая несколько агентов/группу, независимый выбор, закрытие, реальное сохранение/чтение локального состояния, миграцию старого списка и отсутствие живых WebView для локальных вкладок.
- `scripts/check-browser-execution.sh` прошёл на текущем Mac с реальным WKWebView и локальным HTTP-сайтом: фоновые сессии и отказ чтения чужой вкладки, общий предел WebView, разделение загрузок, DOM, формы, скриншоты, остановка, legacy grants, автоматический доступ, личный/групповой чат и модель-заглушка. Внешние API и история пользователя не использовались.
- `scripts/check-agent-progress.sh` прошёл: чат → отдельное обновление → реальное создание документа → итог, восстановление журнала без повтора операции; прежние проверки отказов, остановки и ограниченного вывода.
- В отдельном изолированном окне на физическом Mac визуально проверены: одновременно обе панели; независимые вкладки Mira/Coder/группы и возврат к выбранному разделу; ширина панели 300 и 684 при окне 1280 (252 слева + 336 чат + 8 разделитель + 684 справа); навык → редактор → сохранение/отмена, запуск → выбор версии → стрелка назад; MCP → форма → закрыть; меню → все инструменты; расписание → свой выбор времени/календарь → изменение даты → смена беседы → возврат. Пользовательский Blot не перезапускался.
- Mac Debug и generic physical-device iOS Debug собраны в `.build/xcode` / `.build/ios`; симуляторы не использовались. Подпись Mac проверена. На физический iPhone сборка не устанавливалась, UI iPhone отдельно не проверялся.
- `git diff --check` и обратная проверка сфокусированного патча в текущем проекте прошли. После сборок оставалось около 30 GiB; переиспользованы существующие сборочные каталоги.

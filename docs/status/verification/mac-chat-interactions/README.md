# Упоминания и действия переписки

Проверено 3 ноября 2026 года в BlotMac `--team-design`.

- При первом открытии группы добавляется один пример распределения задач между её текущими участниками. История сохраняется; повторное открытие не дублирует пример.
- Упоминания хранят ID агента. Текст показывает актуальное имя в цвете профиля и его аватар после имени. Имя и аватар не разрываются переносом.
- Пример содержит ответы и реакции агентов. Пользователь может поставить, заменить или снять собственную реакцию на входящее и исходящее сообщение.
- Ответ сохраняет ссылку на оригинал. Цитата доступна в композере и отправленном сообщении; клик по ней возвращает к оригиналу.
- Удержание 0,4 секунды открывает собственное меню с упругой анимацией. Запрашивается тактильный импульс AppKit для поддерживаемого трекпада. Системное и пользовательское уменьшение движения отключают масштабирование.
- Меню сообщения: шесть реакций, ответ, копирование, сохранение в память. Доступно и через правый клик.
- Меню чата: открытие, профиль/настройка группы, память, навыки, расписание, файлы; у агента также добавление в группу, уведомления и прочитанность.

Проверки:

- `bash scripts/check-mac-team-demo.sh`: **87 проверок прошли**, включая совместимость старых сообщений, сохранение реакций/ответов, собственные сообщения, недопустимые ссылки и идемпотентность примера.
- `./script/build_and_run.sh --design`: код 0, без ошибок и предупреждений компиляции в итоговой сборке.
- В UI проверены обычный клик по группе, удержание сообщения агента и собственного сообщения, реакции, цитата в композере, отправка ответа на собственное сообщение, переход к оригиналу, удержание группы и чата агента. Удержание чата само по себе не переключает переписку.
- Физическую силу импульса трекпада дистанционная проверка не измеряет.

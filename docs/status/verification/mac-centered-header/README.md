# Центральный профиль и панель окна macOS

Обновлено 3 ноября 2026 года.

- Переключатель команды и создание перенесены из сайдбара в нативный `ToolbarItem(.navigation)` после кнопок окна. Системное управление окном и его область перетаскивания сохранены.
- В шапке разговора аватар 68 pt расположен по центру над именем. Роль, отметка «Демо» и отдельная скрепка убраны. Устаревшая настройка отметки «Демо» удалена.
- «Действия» находятся слева и раскрываются на месте. Существующая стеклянная поверхность меняет размер через `glassEffectID`, без popover. Список включает профиль, создание группы, память, навыки и файлы.
- Плюс в панели окна расширяется по горизонтали в ту же стеклянную капсулу с действиями создания агента и группы.
- Ширина меню и подписи профиля учитывает доступную ширину шапки. Системное и пользовательское уменьшение движения отключают пружинное раскрытие.
- Шапка закрывает прокручиваемый текст под крупным профилем, чтобы имя и аватар оставались читаемыми.

Проверки: `./script/build_and_run.sh --design` — код 0, без ошибок и предупреждений. В работающем приложении визуально проверены нативное размещение кнопок, центральный профиль, раскрытие и сворачивание «Действий», горизонтальное раскрытие плюса. Изменений демо-данных при проверке не производилось.

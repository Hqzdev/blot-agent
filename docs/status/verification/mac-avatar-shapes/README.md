# Фигуры агентов

Проверено 3 ноября 2026 года.

Общий компонент `WorkspaceAvatar` вынесен из файла стилей в отдельный файл. Положение глаз задано по внутренней области каждой формы. Размер и смещение глаз уменьшены, чтобы они не касались края приплюснутых фигур. Контур `cloud` построен с согласованными касательными между всеми кубическими сегментами, включая замыкание.

- Сборка и запуск BlotMac: `./script/build_and_run.sh --design`, код завершения 0.
- Все десять форм отрендерены непосредственно из исходника SwiftUI через `ImageRenderer` в размерах 100, 36 и 24 pt. Проверены полные глаза и гладкий синий контур: [все формы](all-shapes.png).
- Проверены аватары команды, групп и профиль в работающем приложении: [скриншот](workspace-dark.jpg).

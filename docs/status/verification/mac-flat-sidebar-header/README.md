# Компактная шапка и сплошной сайдбар

Проверено 3 ноября 2026 года.

- У сайдбара удалены внешние отступы, закруглённая рамка и поиск. Команда начинается сразу под нативной панелью окна, фон заполняет левую колонку.
- Нативная панель окна использует `unifiedCompact`. Шапка разговора уменьшена со 136 до 102 pt; верхние отступы кнопок удалены.
- Аватар 56 pt расположен над именем. Имя — отдельная интерактивная капсула Liquid Glass с открытием существующего редактора агента или группы.
- Свёрнутое меню показывает только три точки в кнопке 36 pt. Раскрытие происходит внутри той же стеклянной поверхности, без popover.
- Удалены состояние и фильтр поиска команды. Команда ⌘K доступна в настройках, где остаётся собственный поиск; перечень горячих клавиш обновлён.

Проверки:

- `./script/build_and_run.sh --design`: код 0, без ошибок и предупреждений итоговой сборки.
- В UI проверены отсутствие поля поиска и внешней рамки, открытие профиля по стеклянному имени, раскрытие/сворачивание трёх точек, открытие настроек по ⌘, и фокус поиска настроек по ⌘K, возврат по ⌘[.
- Проверка редактора закрыта без сохранения, демо-данные не менялись.

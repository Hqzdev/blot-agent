# Group participants and roles

Removed role labels from group-message author headers. Avatars and colored names
remain. The group inspector's Overview now has a Participants section containing
the group's actual members, avatars, names, roles and member count.

Each member opens the existing agent profile editor for that specific agent.
Saving from this entry point preserves the current group conversation; regular
agent-profile and new-agent behavior retain their existing navigation.

and the new section. Opened Blot's profile although it is the group's second
member, verified its role/instructions, saved without changes and confirmed the

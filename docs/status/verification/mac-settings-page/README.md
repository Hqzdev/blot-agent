# Страница настроек macOS

Проверено 3 ноября 2026 года в локальной сборке BlotMac (`--team-design`).

Настройки заменяют содержимое основного окна приложения. Модального заголовка, затемнения и кнопки закрытия нет. Слева находятся поиск и 14 разделов, справа — ограниченная по ширине колонка с карточками параметров. Системная верхняя безопасная область сохранена.

Проверки:

- Сборка и запуск: `./script/build_and_run.sh --design`, код завершения 0.
- ⌘, открывает страницу, ⌘K фокусирует поиск настроек.
- Запрос «тема» находит «Оформление»; выбор результата открывает раздел и очищает запрос.
- Светлая и тёмная темы обновляют всю страницу. После проверки восстановлена исходная светлая тема.
- Проверены разделы уведомлений, использования, файлов, профиля, персонализации, MCP и обновлений.
- Gmail открывает редактор подключения; закрытие возвращает на прежнюю страницу настроек.
- Отключение подсказок скрывает строку под композером. При отключённой отправке по Enter нажатие Enter добавляет перенос без отправки.
- Кнопка возврата и ⌘[ возвращают прежнюю переписку, сохраняя черновик.
- Изменённые для проверки параметры восстановлены, тестовый черновик очищен; тестовые сообщения не отправлялись.

Демо-предпочтения уведомлений, запуска и обновлений сохраняются локально. Системные разрешения, автозапуск macOS и сетевое обновление не выполняются. Экспорт пространства реализован через системный диалог сохранения JSON; сохранение файла вручную в этой проверке не выполнялось.

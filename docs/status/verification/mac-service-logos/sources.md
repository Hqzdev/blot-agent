# Источники логотипов приложений

Логотипы включены в локальный каталог `apps/shared/Assets.xcassets`. Общий компонент `MacTeamPluginIcon` сохраняет исходные цвета, пропорции и показывает каждый знак на белой подложке, включая тёмную тему.

| Сервис | Источник ресурса |
| --- | --- |
| Gmail | Существующий мобильный ресурс `PluginGmail` |
| Google Calendar | Существующий мобильный ресурс `PluginCalendar` |
| Google Drive | Существующий мобильный ресурс `PluginDrive` |
| Granola | Существующий мобильный ресурс `PluginGranola` |
| 1Password | Существующий мобильный ресурс `Plugin1Password` |
| Slack | [Фирменный знак на CDN Slack](https://a.slack-edge.com/80588/marketing/img/icons/icon_slack_hash_colored.png) |
| Notion | [Официальная иконка Notion](https://www.notion.com/front-static/logo-ios.png) |
| QuickBooks | [Вектор Simple Icons в фирменном цвете](https://cdn.simpleicons.org/quickbooks/2CA01C) |
| Freshdesk | [Знак продукта на сайте Freshworks](https://www.freshworks.com/beta/icons/template-2026/freshdesk-logo-icon.svg) |
| Composio | [Знак из Composio Brand Hub](https://brand.composio.dev/logos/Logomark-Black.svg) |
| Zapier | [Иконка официального сайта](https://zapier.com/favicon.ico) |
| GitHub | [Официальный вектор GitHub](https://github.githubassets.com/favicons/favicon.svg) |
| beehiiv | [Иконка из ресурсов официального сайта](https://beehiiv-marketing-images.s3.amazonaws.com/Redesign2023/favicon.png) |
| Airtable | [Иконка официального сайта](https://www.airtable.com/favicon.ico) |
| Asana | [Исходный SVG-знак из шапки страницы бренда](https://asana.com/brand); сохранён путь знака с исходной заливкой #F06A6A |
| Adobe | [Вектор Simple Icons 11.15.0](https://cdn.jsdelivr.net/npm/simple-icons@11.15.0/icons/adobe.svg), заливка #EB1000 |
| Atlassian | [Иконка официального портала разработчиков](https://dac-static.atlassian.com/favicon.ico) |

ICO-файлы преобразованы в PNG штатным `sips`. Сетевая загрузка в приложении не используется.

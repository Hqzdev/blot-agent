# Сообщения о ходе работы агента

10 ноября 2026. Изменения применены в текущем проекте для Mac и iPhone.

Агент может отправлять краткие сообщения о ходе многошаговой работы и отдельный итог. Использован существующий устойчивый цикл model/tool: новые сообщения создаются на границах реальных ходов модели, без дробления абзацев или записи каждого токена. Системная инструкция уточнена в пределах прежнего размера, чтобы сохранить небольшие бюджеты запросов.

Имя и аватар показываются один раз в непрерывной серии одного агента и поручения. Другой участник, новый запрос или граница подгруженной истории возвращают подпись. На iPhone сохранены прежние интервалы и статусы пользовательских сообщений.

Под ответами показаны раскрываемые строки реальных вызовов браузера, команд, файлов, Git, Apple-инструментов и MCP. Цветные иконки приложений взяты из существующего каталога. Статусы строятся по явным modelSteps, preparedActions и toolInvocations: очередь, выполнение, разрешение, успех, ошибка, отказ, остановка и неопределённый исход. Текст модели и старый requestJSON не считаются доказательством выполнения. Пустой ответ с вызовом инструмента виден без пустого пузыря. Для старой истории сохранены прежние значки атрибуции, если явных вызовов нет.

По умолчанию видны последние четыре действия, раскрывается не более 64 на сообщение; повторные проверки одного процесса объединяются в пределах ответа. stdout/stderr ограничены и разделены, усечение обозначено; полный журнал открывается через существующий artifact. Параметры скриптов, окружение, поля ввода браузера и непрозрачные ответы плагинов не выводятся автоматически. URL показывается как host, программа — как basename. Нового опроса сети/процессов и постоянной анимации успешных действий нет. Кэш строк ограничен 128 сообщениями и 4 MiB, пересчитываются только изменившиеся зависимости. Видимая история остаётся ограниченной существующим окном.

Общий WorkspaceToolCallIdentity теперь предоставляет прежние browser/session-file UUID через необязательный scope. Формулы и сохранённые идентификаторы не менялись. Схема v3, синхронизация и Java-контур не изменены.

Проверки в текущем проекте:

- Mac Debug и generic physical-device iOS Debug собраны в существующих `.build/xcode` и `.build/ios`, без симуляторов.
- 169 тестов BlotWorkspace прошли, включая ограничения бюджета, остановку процессов, Git и MCP.
- `scripts/check-agent-progress.sh`: одна подпись серии, границы истории, активные/ожидающие вызовы до текста, точные UUID прежних операций, смена approval → unknown → success, отказ/ошибка/остановка, цветная иконка Apple, ограничение вывода, объединение process_status, сохранение кэшей авторов. 5000 обращений к кэшу — около 0,0073 s на этом Mac.
- Полный сценарий WorkspaceStore → LocalWorkspaceService → отдельное сообщение о ходе работы → настоящее создание документа → записанное действие → отдельный итог. Повторная загрузка сохранённого snapshot восстанавливает строки без повторного вызова операции. Модель в стенде сценарная, внешний аккаунт LLM не использовался.
- Регрессии групп, очереди задач и настоящего MCP stdio прошли. Настоящий WebKit проверен: навигация, DOM, подтверждения, разрешения, формы, загрузки, лимит WebView и остановка.
- Проверка длинного чата: 10000 сообщений открываются окном из 80; пагинация, переходы и положение чтения сохранены. Обновления инструментов не инвалидируют авторов, вложения и идентичность чата. 40 насыщенных сообщений × 8 нативных отрисовок — около 0,386 s; это стенд, не замер прокрутки на iPhone.
- Реальный MacLiveTeamConversation отрисован в изолированном нативном окне со сценарными записями. Проверены одна подпись, отдельные пузыри, строки действий, русский текст и цветная иконка напоминаний. Изображение: `.build/agent-progress/native-preview.png`. Тестовое приложение завершено; аккаунт пользователя не менялся. На физическом iPhone интерфейс в этой задаче не запускался.

Свободное место сохранено выше 20 GiB. Посторонние изменения, включая голосовой режим, оставлены в текущем проекте. После fetch подготовлена отдельная `mac/agent-progress` от `origin/mac/main` (`7a7c39b`), только с исходниками этой задачи. Голосовая задача в ветку не включена: одинаковые изменения WorkspaceStore перенесены с учётом отличающегося контекста; остальные фрагменты применились непосредственно. Дополнительная сборка worktree не создавалась: менялись лишь соседние строки независимого голосового режима, а код этой задачи проверен в текущем проекте. Сфокусированный `docs/patches/agent-progress.patch` сохранён относительно исходного текущего проекта; обратная проверка применения прошла. Текущая ветка не переключалась; push/PR не выполнялись.

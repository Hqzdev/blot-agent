# Автоматическая рабочая папка и доступ к браузеру

Изменения от 9 ноября 2026 применены в текущем проекте `mac/workspace` поверх существующих Native XPC, MCP, групп и встроенного браузера. Настройка Finder и плагинов для работы с файлами больше не требуется. В реальном аккаунте автоматически включены встроенные файловые и браузерные инструменты.

## Рабочие файлы

При загрузке приложения подписанный пользовательский XPC-исполнитель подготавливает `~/Blot`. Путь выбирает сам исполнитель; модель не может подменить его. Для каждого аккаунта, рабочего пространства и чата создаётся `Sessions/<owner>/<workspace>/<conversation>/`: `Files` для работы агента, `Session.json` и `Messages` для истории, `Artifacts/<id>/<name>` для связанных документов и вложений. Основная база остаётся в контейнере приложения. История зеркалируется по событиям с объединением обновлений, без периодического обхода полной резервной копии и без записи каждого токена; сохраняются завершённые сообщения. Индекс хешей исключает повторные записи после перезапуска. Связанные артефакты копируются с проверкой хеша; изменённые пользователем копии не перезаписываются.

Шесть инструментов `workspace_directory`, `workspace_list_files`, `workspace_read_file`, `workspace_write_file`, `workspace_create_directory`, `workspace_request_directory` доступны без подключения плагина. Внутри папки сессии агент создаёт вложенные папки и текстовые файлы, читает и изменяет их. Изменение существующего файла требует исходного SHA-256; создание — `expected_hash=missing`. Операции выполняются через дескрипторы каталогов, запрещают выход через `..`, симлинки и `.git`; запись атомарная. Ограничены размер текста, чтение и количество элементов списка.

Для другого места агент объясняет цель и вызывает системный выбор папки. При переданном имени Blot сам создаёт дочернюю папку в выбранном пользователем месте. Bookmark и абсолютный путь остаются локальными; разрешение связано с агентом и чатом, доступно для просмотра и отзыва в настройках разрешений. Отказ не повторяет запрос автоматически. Внешние папки не удаляются при удалении аккаунта; удаляется только его помеченное пространство в `~/Blot/Sessions`.

Вызовы проходят журнал PreparedAction/ToolInvocation. Неопределённый результат блокирует новые изменения до сверки владельцем; подтверждение результата завершает служебную задачу без повторной записи. Режим наблюдения запрещает запись, создание папок и документов. Старые задачи сохраняют зафиксированные ограничения. Произвольный CLI этим изменением автоматически не разрешается.

## Встроенный браузер

В реальном аккаунте девять инструментов браузера добавляются автоматически: агент может открывать HTTP(S)-сайты, перечислять и читать вкладки владельца без формы «Добавить текущий сайт и агентов чата». Для этого пути не читаются прежние credentials разрешений сайтов. Старый явный режим сохранён для совместимости и изолированных проверок.

`browser_tabs` перечисляет доступные вкладки без query/fragment в URL. `browser_snapshot` читает выбранную либо указанную пользовательскую вкладку, возобновляя при необходимости приостановленный WebKit в пределах бюджета живых представлений. Чужая пользовательская вкладка доступна через этот путь для чтения; действия над страницей сохраняют существующие ограничения области и точное подтверждение. Значения полей и cookies не выдаются модели. Вход, CAPTCHA и 2FA остаются за владельцем. В группе обычный запрос о странице может получить инструменты чтения, приветствие не запускает работу.

Автоматические 6 файловых, 9 браузерных, `file_read` и `document_create` не расходуют 100 мест пользовательского назначения инструментов. Сохранены проверки текущего агента, режима наблюдения, контекста, закреплённых разрешений задачи и неразрешённых результатов.

## Совместимость и проверки

Добавлены приватные Swift XPC-операции подготовки папки, истории, scoped read/write/list/mkdir, копирования артефактов и удаления пространства аккаунта. Подпись и проверка вызывающего приложения сохранены. Реплицируемый v3-контракт и Java DTO не менялись. Новые автоматические назначения аддитивны; локальные bookmarks не синхронизируются. На iOS локальные Mac-файловые операции отключены.

Проверено в текущем проекте:

- 169 тестов Swift-ядра и 18 тестов Apple-интеграций, включая CAS, выход из каталога, симлинки, отзыв доступа, режим наблюдения, потерю ответа после записи и восстановление без повтора.
- Настоящий подписанный sandboxed XPC на текущем Mac: личный чат и группа → папки/запись/чтение → история; очередь использует ту же сессию; PDF из контейнера появляется в видимой папке Artifacts. Тестовые пространства удалены своим scoped-оператором.
- Реальный системный выбор внешней папки, bookmark, создание дочерней папки и чтение/запись прошли. UI-инструмент Accessibility не смог подключиться к стенду вовремя; результат подтверждён callback системной панели и файловыми проверками стенда. Созданная тестовая дочерняя папка удалена после проверки её точного содержимого; родитель сохранён.
- Реальный WebKit: автоматическое открытие, чтение вкладок без настройки в личном чате и группе, перечисление трёх ручных вкладок, возобновление приостановленной вкладки, лимит живых WebView и прежние подтверждения действий.
- Регрессии групп, очереди задач, MCP и расписаний; 167 проверок схем. Java application/infrastructure: Gradle offline успешно, 9 задач из текущего кэша.
- Финальные Mac и generic physical-device iOS сборки без симуляторов. Mac bundle проверен ad hoc подписью; это не проверка Developer ID/notarization. Физический iPhone недоступен (offline), выполнение на нём не проверено. Открытый пользователем Blot не перезапускался: изменения вступают в силу после запуска новой сборки.

Использованы существующие `.build/xcode` и `.build/ios`. Во время проверки был обнаружен уход ниже 20 GiB; одноразовые стенды и восстанавливаемые compiler/index caches удалены после окончания использовавших их процессов. Финальные сборки выполнены последовательно. Исходные backups, журналы и по одной повторно используемой сборке каждой платформы сохранены.

`docs/patches/automatic-workspace.patch` содержит только изменения этого блока относительно сохранённого исходного состояния текущего проекта. Он применяется после предшествующих native/MCP/group/browser изменений и двух браузерных патчей. Поскольку `origin/mac/main` ещё не содержит этих зависимостей, сфокусированная ветка `mac/automatic-workspace` хранит патч и этот отчёт; полная проверенная реализация остаётся в текущем проекте. Публикация ветки и PR не выполнялись.

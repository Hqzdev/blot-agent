# Проверка после пользовательского перезапуска

10 ноября 2026. Проверка обнаружила оставшийся сбой; не считать исходный пользовательский сценарий полностью исправленным.

Процесс из Xcode действительно перезапущен и содержит новые `select_group_route`, обязательный выбор инструмента и последовательность операций. Старую сборку причиной этого результата считать нельзя.

В консоли Xcode у запроса со скриншота: `Group routing envelope valid=false`, затем `Group route mode=specialist firstTool=auto`; дальше только один модельный ход без записей о возвращённых инструментах. При ошибке декодирования маршрута прежний fallback запускал обычную генерацию, и модель могла выдать текст о мнимом выполнении. Точное поле отклонённого объекта уже не было доступно в локальной переменной; причины вроде неверного UUID не подтверждены.

В коде fallback убран. Для некорректного решения допускается одна попытка исправить управляющий объект по той же схеме и составу группы, в пределах существующего бюджета. Если и она невалидна, ответ завершается ошибкой без исполнения операций и публикации мнимого успеха. Корректный маршрут не требует дополнительного запроса. Состав группы и текущие разрешения проверяются по-прежнему.

Пользователь отдельно разрешил один новый тест в Product Review через тот же GigaChat с историей этой группы. Выполнен ровно один новый тестовый запрос: новая папка «Проверка прогресса 2», новый test.md, обратное чтение. Одноразовая точка останова в уже подключённом отладчике Xcode показала валидный маршрут с тремя операциями. Процесс продолжен; точка была одноразовой. Дополнительных повторов истории не выполнялось.

Результат в пользовательском приложении: настоящий `workspace_create_directory` завершился успешно; настоящий `workspace_write_file` вернул ошибку. Обратное чтение не исполнялось, итог честно сообщил о неудачной записи. В чате появились отдельные строки успешного и неуспешного действия с одной подписью CEO. Это подтверждает показ настоящих этапов, но НЕ подтверждает создание test.md в пользовательской группе. Причина конкретной ошибки записи ещё не установлена; объяснение модели про доступ не считается самостоятельным доказательством системного отказа.

Проверки изменения маршрутизации:

- Локальный сценарный стенд групп прошёл, включая новый сценарий «невалидный маршрут → одна корректировка → настоящий document_create» и сценарий «два невалидных решения → ошибка, без рабочего инструмента и завершённого ответа». Сценарии владельцев, командной работы, упоминаний, планов и остановки сохранены.
- Mac Debug и generic physical-device iOS Debug собраны в прежних `.build/xcode` и `.build/ios`, без симуляторов. Подготовленный Mac bundle проверен отдельно от запущенного приложения. Ядро не менялось после ранее пройденных 174 тестов.
- Дополнительный живой тест с полностью вымышленными данными и отдельной базой прошёл: модель создала папку, записала точное содержимое «Проверка Blot» в test.md с expected_hash=missing и прочитала его обратно; содержимое файла проверено локально. Использовалась та же реализация NativeExecutor с тестовым workspaceHome, без XPC и без истории пользователя. Этот тест не доказывает исправления ошибки записи в пользовательском Product Review.

Запущенный экземпляр пользователя не закрывался и его bundle не перезаписывался. Исправление fallback находится в текущих исходниках и подготовленной `.build/xcode` сборке; текущий процесс под Xcode был запущен до этого последнего изменения. Пользователь ранее выбрал самостоятельный перезапуск. Проверка на физическом iPhone не выполнялась. Свободное место выше 20 GiB.

Фокусированный патч: `docs/patches/agent-progress-routing-repair.patch`, поверх `mac/agent-progress` f741c87. Посторонние правки и голосовой режим сохранены. Push/PR не выполнялись.

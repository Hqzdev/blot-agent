# Проверка системных интеграций Apple — 4 ноября 2026

Реализация и ограничения: [Системные приложения Apple](../integrations/apple-apps.md).

Проверено:

- macOS Debug: сборка `BlotMac` через `script/build_and_run.sh --build-only`; sandbox включён, в подписанном приложении присутствуют разрешения EventKit, Contacts и ограниченная автоматизация Mail/Notes.
- Подпись приложения и вложенных компонентов: `codesign --verify --deep --strict`.
- iOS Debug: сборка для arm64 Simulator с `CODE_SIGNING_ALLOWED=NO`.
- `BlotAppleIntegrations`: 13 тестов, включая полный цикл модели, обнаружение инструментов, запись, сохранённый результат, отзыв доступа, отказ пользователя, отсутствие повторов после неизвестного исхода и ручное восстановление.
- `BlotWorkspace`: 63 теста рабочего пространства.
- Проверочное приложение `check-workspace-v3.sh --local-only`: команды UI, поток ответов, явный повтор и повторное открытие рабочего пространства с внедрённой моделью.
- Java: `:core:compileJava :core:test spotlessCheck` на локальном JDK 25.
- JSON Schema: 167 fixtures, включая старые Connection без новых полей.
- `git diff --check`.

Автоматические проверки не выдавали разрешения на личные системные данные и не изменяли почту, контакты, календари или заметки пользователя. Реальный App Store/TestFlight релиз и нотариализация не выполнялись.

Физический iPhone числится сопряжённым, но `devicectl device info details` сообщил `Device State: unavailable` и невозможность установить соединение. Полный сценарий реальная модель → системные данные, выдача/отзыв TCC и работа на физическом iPhone остаются ручной приёмкой по инструкции интеграций. Компиляция AppleScript проверена без выполнения команд Mail/Notes.

Оригинальные iOS-иконки получены из метаданных Apple App Store; источники сохранены отдельно. Допустимость распространения графики необходимо подтвердить перед публичным выпуском.

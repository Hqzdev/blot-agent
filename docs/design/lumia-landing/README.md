# Исходники лендинга Lumia

Лендинг Lumia сохранён как материал проекта по решению владельца от 15 ноября 2026. Он не подключён к веб-приложению Blot. Основной сайт остаётся в `landing/`.

Здесь сохранены исходный маршрут `app/(landing)/page.tsx`, компоненты `components/landing/` и изображение `public/landing/`. Их байты при переносе сверены с Lumia commit `9d9eecd94063c6f4b9e67d7e7ffa9d1182b0dcdb`. Это исходники для последующей работы, а не отдельное запускаемое приложение. Полный исходный репозиторий с Git сохранён локально в `.build/import-origins/2026-11-15/Lumia`.

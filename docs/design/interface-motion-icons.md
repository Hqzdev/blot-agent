# Иконки и движение интерфейса

Общие компоненты Mac и iPhone находятся в `packages/BlotDesign`.

- `BlotGlyph` — каталог семантических иконок. `BlotIcon` рисует только SVG из `BlotIcons.xcassets`; прежние ключи SF Symbols преобразуются в контурные иконки этого каталога.
- Новые иконки: сетка 24×24, штрих 1.6, круглые окончания и соединения, без заливки. Цвет задаёт вызывающий экран. Проверяйте поддержку ключа через `BlotGlyph.resolve(symbol:)`.
- `BlotIconSize`: 14 для подписей, 18 для контролов, 20 для навигации, 24 для крупных действий, 28 для иллюстраций. Размер не зависит от жирности текста.
- `BlotInterfaceMotion`: нажатие 120 мс, короткая смена состояния 150 мс, обычный переход 220 мс, панель 280 мс. Пружины без отскока; сдвиг появляющегося контента — 6 pt.
- `BlotPressFeedback` и `BlotPlainButtonStyle` обеспечивают общий отклик кнопок. Приложения используют `KMotion` как короткое имя общих токенов.
- `kMotionRoot` объединяет системное уменьшение движения и предпочтение `blot.v3.reduceMotion`, публикует окружение и отключает анимации. На Mac настройка доступна в «Настройки → Общие → Движение».
- Анимация привязана к конкретным состояниям: выбранному разделу, видимости панели, списку идентификаторов сообщений или карточек. Не привязывайте анимацию контейнера к каждому изменению текста формы.

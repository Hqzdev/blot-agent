# Blot 1.0 Beta

Первая публичная бета для Mac и iPhone — 4 ноября 2026 года.

## Что вошло

- Нативные приложения macOS и iOS: чаты, агенты, проекты, файлы, настройки, светлая и тёмная темы.
- Локальное рабочее пространство на SQLite: сохранение переписки, сообщений, результатов, памяти и состояния задач между запусками.
- Профили агентов с именем, образом, инструкциями, выбором модели и инструментов. Группы с редактированием участников, ролей и общим бюджетом.
- Потоковые ответы модели, сохранение модельных шагов и результатов инструментов, учёт токенов, отмена, явный повтор и компактирование контекста.
- Работа с прикреплёнными файлами, создание документов, подготовка действий и подтверждения пользователя.
- Браузерный вход с PKCE и возвратом в приложение, восстановление сессии и отдельные локальные данные аккаунтов. На сайте добавлены варианты входа через почту, Google и Яндекс.
- Резервные снимки чатов и проектов в аккаунте. Основа протокола прямой синхронизации между устройствами.
- Интерфейсы нативных интеграций Apple с выбором ресурсов и разрешений. Возможности зависят от платформы, системного доступа и конкретного приложения.
- Доработки интерфейса: отзывчивость чатов iPhone, целые ответы и индикатор размышления, анимированные аватары, персональное приветствие, меню групп, настройки и каталог на Mac.
- Обновлённый сайт, документация, история изменений и прямые ссылки на установщики в GitHub Releases. Android и Windows отмечены как **Soon**.

## Скачать и установить

**Mac:** `Blot-1.0-Beta-macOS-arm64.dmg`. Нужны Apple Silicon и macOS 26 или новее. Откройте DMG и перенесите Blot в «Программы». Приложение подписано ad hoc, без Developer ID и нотарификации Apple. macOS может потребовать разрешить открытие в «Системные настройки → Конфиденциальность и безопасность».

**iPhone:** `Blot-1.0-Beta-iOS.ipa`. Нужна iOS 26 или новее. IPA не подписан для публичного распространения: подпишите его собственной Apple developer identity через инструмент для sideloading. Нажатие на скачанный IPA само по себе приложение не установит. Это не TestFlight и не App Store; срок действия и возможности установки определяются вашей подписью и профилем.

В публичную сборку **не включены личные ключи модели**. После входа добавьте в настройках Compatible API собственные endpoint, model ID и API key. Для агента выберите Compatible API. Новые агенты в Release используют этот вариант по умолчанию. Ключ оплачивается и предоставляется вашим провайдером отдельно; общего бесплатного доступа к GigaChat в этой бете нет.

Контрольные суммы обоих файлов опубликованы в `SHA256SUMS.txt` рядом с установщиками.

## Ограничения первой беты

- Полный продукт и все сценарии ТЗ ещё не завершены. Сборка и компонентные тесты не заменяют проверку каждого сценария на физических устройствах.
- Android и Windows: **Soon**, установщиков пока нет.
- Прямой обмен по Wi-Fi/Bluetooth, поиск устройств, QR, передача вложений и отзыв доверия ещё требуют завершения и проверки как единого сценария.
- Фоновое исполнение расписаний и полный цикл внешних интеграций ещё дорабатываются. Наличие экрана подключения не означает поддержку всех операций сервиса.
- Часть полированных экранов остаётся предпросмотром; живое рабочее пространство может отличаться.
- Резервные снимки аккаунта передаются по HTTPS и доступны серверу; сквозное шифрование для облачных резервных копий не заявляется. Байты вложений и локальные credentials в снимки не входят.
- Для экспериментов используйте копии важных данных.

## Сборка из исходников

Нужны Xcode с SDK macOS/iOS 26+ и JDK 25. Публичные параметры находятся в `config/apple-public-beta.env`; секреты туда не добавляются. Запуск: `bash scripts/package-beta.sh`. Скрипт собирает Release, проверяет профиль без ключей, формирует DMG, неподписанный IPA и SHA-256 в `.build/releases/v1.0.0-beta.1/`.

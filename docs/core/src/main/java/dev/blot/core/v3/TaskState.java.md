# `TaskState.java`

Жизненный цикл поручения v3. Описывает черновик, планирование, утверждение, очередь, работу, ожидание, паузу и конечные исходы.

[Исходник: `backend/core/src/main/java/dev/blot/core/v3/TaskState.java`](../../../../../../../../../backend/core/src/main/java/dev/blot/core/v3/TaskState.java)

Модуль: [core](../../../../../../../README.md). Раздел: [Сгенерированный контракт v3](index.md).

**Значения** — `DRAFT`, `PLANNING`, `WAITING_APPROVAL`, `QUEUED`, `RUNNING`, `WAITING_USER`, `PAUSED`, `COMPLETED`, `FAILED`, `CANCELED`, `INTERRUPTED`.

Файл генерируется из [контракта v3](https://github.com/Hqzdev/kiln-agent/blob/4e6c47f65e0e734dedc122d586c7bb67d37395a3/contracts/v3/model.json).

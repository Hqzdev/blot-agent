# `AgentCapability.java`

Перечисляет категории действий, которыми может обладать ранний профиль агента. Эти значения используются при проверке выданных возможностей.

[Исходник: `backend/core/src/main/java/dev/blot/core/agent/AgentCapability.java`](../../../../../../../../../backend/core/src/main/java/dev/blot/core/agent/AgentCapability.java)

Модуль: [core](../../../../../../../README.md). Раздел: [Ранняя модель агентов](index.md).

**Значения** — `PROJECT_READ`, `ARTIFACT_READ`, `TASK_MESSAGE`, `USER_QUESTION`, `TASK_PLAN`, `TASK_ASSIGN`, `TASK_EXECUTE`, `RESULT_REVIEW`, `QUALITY_REPORT`, `SECURITY_REPORT`, `PROJECT_WRITE`, `PROCESS_RUN`, `EXTERNAL_ACTION_PREPARE`, `EXTERNAL_ACTION_EXECUTE`.

# Grok Bot функции интерфейс и руководства

Проверено 16 ноября 2026 года. Объект — Grok Bot с x.ai/bot, отдельное приложение с постоянными агентами. Обычный Grok Chat, Imagine и Companions не включены. Grok Bot объединяет переписку, память роли, общий облачный компьютер, подключённые приложения, навыки, расписания и результаты работы. В версии 1.0 к ним добавлены командные сценарии. ## Как устроен продукт

Основная единица — постоянный Bot с ролью и контекстом. Чат содержит сообщения, вызовы инструментов, вопросы, черновики, согласования и результаты. Успешную процедуру сохраняют как skill; routine запускает работу по времени или событию. Компьютер, приложения и часть навыков разделяются ботами аккаунта. Память роли и её регулярные задачи принадлежат боту. Основной бот координирует специалистов. [Как работает Grok Bot](https://docs.x.ai/grok-bot/how-grok-bot-works).

### Различия которые влияют на архитектуру

| Понятия | Различие |
| --- | --- |
| Личный Bot и Team Bot | У командного бота есть общий доступ, роли участников и управление знаниями. |
| Share template и Share Bot | Шаблон создаёт независимую копию; Team Bot остаётся одним ботом для команды. |
| Skill и routine | Skill определяет способ работы; routine — владельца и момент запуска. |
| Отдельный экран и отдельная машина | Личные боты используют разные экраны общего компьютера аккаунта. Это не изоляция файлов и входов. |
| Установлено и авторизовано | Added не означает, что вход в приложение завершён. |
| Slack connector и Slack channel | Коннектор действует через подключённый аккаунт; канал позволяет людям обращаться к боту в Slack. |
| Уведомление и фоновая задача | Выключение Notifications не выключает инициативные check-ins и не приостанавливает routine. |

Источники: [Team Bots](https://docs.x.ai/grok-bot/team-bots), [компьютер и приложения](https://docs.x.ai/grok-bot/computer-and-apps), [инициатива](https://docs.x.ai/grok-bot/initiative), [навыки и расписания](https://docs.x.ai/grok-bot/skills-routines-and-automations).

## Расхождения внутри официальных материалов

1. Руководство Message and collaborate говорит, что запросы согласования не появляются в группах. Руководство Approvals описывает карточки в группе и право ответа только инициатору. Без проверки конкретной версии нельзя считать поддержку карточек в группах установленной. [Chat](https://docs.x.ai/grok-bot/chat-and-collaboration), [Approvals](https://docs.x.ai/grok-bot/approvals-security-and-privacy).
2. Обзор How Grok Bot Works обобщённо относит карты Vault к данным, не показываемым боту. Специализированная страница Vault прямо говорит, что в Grok Bot app бот может видеть номер и security code сохранённой карты. Для модели хранения следует ориентироваться на конкретное описание Vault, а не на общее обещание. [Overview](https://docs.x.ai/grok-bot/how-grok-bot-works), [Vault](https://docs.x.ai/grok-bot/vault).
3. Страница Mobile сначала исключает обновление и recovery компьютера на телефоне, а ниже перечисляет Reset в Settings. Наличие конкретного действия нужно проверять в мобильной версии. [Mobile](https://docs.x.ai/grok-bot/mobile).
4. Маркетинговое «у каждого бота свой компьютер» не означает отдельные VM и доступы для каждого личного бота. [FAQ](https://docs.x.ai/grok-bot/faq).

## Существенные пределы

| Область | Публично описанный предел |
| --- | --- |
| Группа | 2–6 ботов; live voice — один бот. |
| Teach a task | До 10 минут, без записи микрофона; созданный skill требует проверки. |
| Routines | До 50 на бота, интервал не меньше 5 минут, 20 последних запусков в истории. |
| Вложения desktop | 20 на сообщение; изображения 25 MB каждое и 200 MB вместе; прочие файлы 250 MB; видео 1 GB. |
| Создаваемое видео | 1–15 секунд; 480p или 720p по запросу. |
| Custom Rules | До 20 Allow и 20 Ask first; до 1000 символов на правило. |
| Фоновое согласование | Может истечь через 30 минут. Чатовый запрос не истекает по таймеру. |
| Возможности телефона | Приложение должно быть открыто. Android notification reading удалено в 1.18.0. |
| Pages | Постепенное включение; Files and results отдельно указывает недоступность Enterprise. |
| @bot в X | Есть региональные исключения; видео и GIF в исходном контексте могут блокировать передачу. |

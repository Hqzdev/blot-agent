# `BlotController.java`

Обслуживает служебные проверки локального сервера. `/health` подтверждает, что процесс отвечает, а `/ready` проверяет готовность хранилища.

[Исходник: `backend/api/src/main/java/dev/blot/api/BlotController.java`](../../../../../../../../backend/api/src/main/java/dev/blot/api/BlotController.java)

Модуль: [api](../../../../../../README.md). Раздел: [Запуск сервера и ответы](index.md).

## HTTP-маршруты

- `GET /health`
- `GET /ready`

# Системные приложения Apple

Blot выполняет интеграции локально на macOS/iOS 26+. Реализация находится в `packages/BlotAppleIntegrations`; рабочий `LocalWorkspaceService` добавляет `AppleToolProvider` в тот же `WorkspaceToolRegistry`, который вызывает модель. Демо использует общий каталог, но не подключает настоящие аккаунты.

## Подключение

Откройте маркет → «Приложения Apple» → приложение. Выдайте системное разрешение, выберите ресурсы и агентов, затем сохраните доступ. По умолчанию выбран основной агент. Разрешены чтение, создание и обычное редактирование; отправка писем, удаление, перемещение файлов/писем и запуск команд согласуются отдельно. Результаты инструментов входят в контекст выбранной пользователем модели.

| Приложение | Способ доступа | Ограничения |
| --- | --- | --- |
| Календарь | EventKit, полное разрешение на события | Только выбранные календари. Изменения повторяющегося события относятся к одному вхождению; требуется `occurrence_start` из поиска. |
| Напоминания | EventKit, разрешение на напоминания | Только выбранные списки; текст, срок, завершение. Специальные функции интерфейса Reminders не эмулируются. |
| Контакты | Contacts | На iOS учитывается ограниченное разрешение; заметки контактов и закрытые поля не запрашиваются. |
| Finder / Файлы | Системный выбор папок, security-scoped bookmarks, NSFileCoordinator | Bookmarks хранятся локально. Текстовые файлы до 48 KiB; список до 100 объектов; рекурсивный поиск по имени до 100 совпадений с явной отметкой усечения после 10 000 просмотренных объектов; удаление непустой папки запрещено. |
| Почта на Mac | Фиксированные операции Apple Events | Выбранные аккаунты. Поиск по теме или отправителю, чтение, текстовые черновики и ответы, перемещение, удаление и отправка. Вложения в черновике пользователь проверяет в Почте; API не даёт полного предпросмотра вложений исходящего сообщения. |
| Почта на iPhone | MFMailComposeViewController | Нет чтения ящика. Пользователь сам отправляет письмо или сохраняет черновик. Возврат `submitted_to_mail` не означает подтверждённую доставку. |
| Заметки на Mac | Фиксированные операции Apple Events | Выбранные папки; заблокированные заметки исключены. Изменение заменяет текст и форматирование. |
| Заметки на iPhone | Недоступно в первой версии | Карточка показывает «Доступно на Mac». |
| Команды | `shortcuts://x-callback-url/run-shortcut` | Пользователь задаёт точное имя существующей команды и явно подтверждает проверочный запуск с пустым входом. Подключить можно после успешного callback. Каждый агентный запуск подтверждается отдельно; имя не гарантирует неизменность содержимого команды. |

При отрицательном ответе системы подключение не сохраняется. Существующее подключение проверяется заново при открытии приложения и перед каждым вызовом. Права другого устройства не принимаются за локальное разрешение. Передача действий с iPhone на Mac в эту версию не входит.

## Выполнение и журнал

1. Каталог задаёт стабильные `apple.*` идентификаторы и типизированные инструменты `apple_<app>_<operation>`.
2. Доступные схемы фильтруются по устройству, подключению, системному доступу и конфигурации агента. Сначала модель получает `*_resources`; после выбора приложения раскрываются его операции, чтобы не расходовать контекст на все приложения сразу.
3. Исполнитель повторно проверяет актуальную конфигурацию, выбранные ресурсы и сохранённое правило. После ожидания пользователя проверки повторяются.
4. Любая запись создаёт `PreparedAction`. Для обычных изменений одноразовый grant выводится из явно выданного правила подключения; значимые действия ждут решения в нативном интерфейсе.
5. Из обычного чата создаётся связанная локальная задача. Результат `ToolInvocation` сохраняется до продолжения разговора; успешная задача завершается.
6. Повтор того же вызова возвращает сохранённый результат. Повтор с изменёнными аргументами отвергается. При неизвестном исходе повторная запись автоматически не запускается.

Вызов с неизвестным исходом приостанавливает новые записи через этот плагин на устройстве, включая новые вызовы с другими идентификаторами. Пользователь проверяет объект в системном приложении и отмечает «Проверено: выполнено» или «Проверено: не выполнено» в карточке подключения. Это решение не доступно как инструмент модели и не запускает повторную операцию. После перезапуска незавершённые внешние вызовы переводятся в `UNKNOWN`. Потерянный callback «Команд» также считается неизвестным исходом. Токен callback случайный, одноразовый и связан с ожидающим запуском; устаревшие ответы игнорируются. Фоновое непрерывное выполнение на iOS не предполагается.

AppleScript не принимается от модели: фиксированный исходник вызывается через параметры Apple event. `NSAppleScript` исполняется на главном потоке согласно ограничениям Foundation; у операций Mail/Notes установлен timeout 30 секунд. Системный диалог автоматизации может потребовать участия пользователя. Sandbox остаётся включённым; разрешены только Mail и Notes. Отказ TCC или sandbox не обходится.

## Контракты и ресурсы

`Connection` содержит необязательные `pluginId`, `resourceIds`, `agentIds`, `allowedOperations`, сохраняет старое поле `service` и существующий `deviceId`. Старые JSON-записи читаются без новых полей. Java DTO сохраняет старый конструктор; генератор учитывает совместимость. Локальные bookmarks и проверенные имена команд не входят в репликацию.

На Mac иконки извлекаются во время отображения через `NSWorkspace`. Для iOS включены оригинальные иконки из публичных метаданных Apple App Store; ссылки и владелец записаны в файле `docs/integrations/apple-app-icon-sources.json` репозитория. Эти метаданные сами по себе не предоставляют лицензию на распространение графики: перед публичным выпуском владелец продукта должен подтвердить допустимость её использования по [условиям Apple](https://www.apple.com/legal/intellectual-property/guidelinesfor3rdparties.html). SF Symbols и private API не используются как замена оригинальных иконок приложений.

App Intent «Открыть приложения Apple в Blot» открывает маркет из Siri/«Команд». App Intents не предоставляют общий доступ к данным других приложений.

## Проверка

Автоматически проверяются разрешённые ресурсы и агенты, отзыв доступа, отключение во время подтверждения, одноразовое исполнение записи, изменённые аргументы повторного вызова, неизвестный исход, отказ пользователя, границы папок и символические ссылки, компиляция фиксированных AppleScript и чтение старого Connection.

```sh
swift test --disable-sandbox --package-path packages/BlotAppleIntegrations
swift test --package-path packages/BlotWorkspace
./script/build_and_run.sh --build-only
xcodebuild -project apps/Blot.xcodeproj -scheme BlotIOS -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build
python3 scripts/check-v3-schemas.py
```

Для ручной приёмки на тестовых данных: подключить каждое приложение, создать/изменить объект через агента, проверить результат в системном приложении; отказаться от удаления, затем разрешить удаление тестового объекта. Отозвать разрешение в системных настройках и убедиться, что следующий вызов отвергается. Для «Почты» проверить адресатов, отправителя и тело на подтверждении. Для «Команд» проверить успех, ошибку, отмену и отсутствие callback. На iPhone отдельно проверить системный редактор письма, выбор папки, ограниченный доступ к контактам и возврат после перехода в «Команды».

Автоматические тесты используют контролируемый системный исполнитель и не изменяют личную почту, контакты и календари. Проверка на физическом iPhone, ручная выдача TCC-разрешений и полный сценарий реальная модель → реальные системные данные требуют отдельного пользовательского прогона; сборка и тесты не заменяют эту приёмку.
